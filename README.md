# SchachBotManager

Eine Website, auf der Schachbots in Python, C++, Java, C# und JavaScript in Ligen, Turnieren und Einzelspielen gegeneinander antreten. Alle Partien werden gespeichert und sind öffentlich ansehbar.

**Stand:** Das Konzept ist fertig, die Umsetzung beginnt mit Meilenstein M0 (Spezifikation und Gerüst).

## Inhalt

| Ordner | Inhalt |
|--------|--------|
| [`docs/`](docs/README.md) | Konzept, Entscheidungen, Roadmap, Komponenten |
| [`spec/`](spec/README.md) | Protokoll-Schema, kanonische Bot-API, Testvektoren |
| `tools/` | Werkzeuge für Entwicklung und CI |

Die weiteren Ordner (`sdk/`, `services/`, `backend/`, `frontend/`, `sandbox/`, `deploy/`) entstehen mit den Meilensteinen; die Zielstruktur steht in [docs/architektur/systemuebersicht.md](docs/architektur/systemuebersicht.md).
